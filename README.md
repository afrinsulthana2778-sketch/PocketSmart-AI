# PocketSmart AI

PocketSmart AI is a Generative AI powered budget planning assistant.

It provides:

- Home Interior Planning
- Party Planning
- Jewelry Planning
- Gemini AI recommendations
- Optional jewelry outfit image analysis
- User registration and login
- Recommendation history
- SQLite database
- FastAPI backend
- Jinja2 frontend
- Responsive UI
- Automated tests
